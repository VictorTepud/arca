## Decisiones (resumen; se amplían abajo)
- **RelPath vive en arca-7z** (la spec 09 deja a discusión del arquitecto si va en
  pkg-model): T04 (pkg-model) corre en paralelo y no puedo depender de él ni
  editarlo. NOTA(agent) en el código para unificar cuando pkg-model aterrice.
- `EntrySink` es **trait** (dyn) y el sink de filesystem concreto es `DirSink`:
  la spec mezclaba `pub struct EntrySink` con `sink: &mut dyn EntrySink` (un
  struct no puede ser `dyn`). Mantengo la firma de `extract` literal a la spec;
  el nombre del struct concreto es el desvío documentado.
- Errores de sevenz-rust2 → `ArcaError`: `Io(io)` directo; el resto se envuelve
  en `ArcaError::Io(io::Error::new(InvalidData, fuente))` para conservar el
  texto exacto ("unsupported filter" de spec 09 §5 sigue siendo diagnosticable).
  `ArcaError::Internal(&'static str)` perdía el nombre del método.
- Decode **single-thread** (`set_thread_count(1)`) para acotar memoria (LZMA2-MT
  replica buffers por hilo).
